# Colors

All color values are **oklch**, declared in `:root` and exposed to Tailwind via `@theme inline` as
`--color-*` — so `bg-background`, `text-muted-foreground`, `border-border` resolve automatically.
**Never write raw colors** (`text-white`, hex, rgb) in components.
