# Portfolio Design System

The visual system behind the portfolio — a **dark-only**, token-driven UI kit built on
[shadcn/ui](https://ui.shadcn.com) (New York style) + Radix primitives, styled with Tailwind v4.
Every story on this site renders the real component from `src/components/ui/**`.

## How this site is organized

- **Foundations** — the raw material: [Colors](?path=/docs/design-system-foundations-colors--docs),
  [Typography](?path=/docs/design-system-foundations-typography--docs), and
  [Tokens & Effects](?path=/docs/design-system-foundations-tokens--docs). All values are oklch and
  declared once in `src/styles.css`.
- **UI** — every primitive (Button, Card, Dialog, …) with an interactive **Docs** page and live
  **Controls**. These are the same stories the design-sync pipeline ships to claude.ai/design.

## Principles

1. **Tokens are the source of truth.** Components never use raw colors — only semantic Tailwind
   utilities backed by `--color-*`. Edit a token in `src/styles.css`, every component follows.
2. **Dark-only.** `html { color-scheme: dark }`; the app never toggles a `.dark` class. The dark
   look comes from `:root`, not a theme class.
3. **Primitives stay thin.** `src/components/ui/**` is the shadcn surface (lint-ignored, no app
   logic). Composition happens in feature folders.

## Using a component

```tsx
import { Button } from "@/components/ui/button"

export function Example() {
  return (
    <Button variant="default" size="lg">
      Get in touch
    </Button>
  )
}
```

Open any component in the sidebar, flip variants in **Controls**, and copy the generated code from
the **Docs** tab.
