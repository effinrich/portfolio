# LinkedIn — About

I've spent 15 years building the front end — from browser-based AR try-on apps
years before "WebAR" had a name, to 200-component React UI libraries, to the
design systems and developer tooling that teams actually build their products on.

My craft is React and TypeScript at the surface where design meets product:
Storybook-driven design systems, accessible component libraries, data-viz UIs,
and the workflows — Chromatic visual regression, feature-based architecture,
custom hooks — that keep design, product, and engineering shipping in lockstep.
I've done it as an IC and as an Engineering Director, across five 0-to-1
startups, usually as the person translating between designers, product, and
backend.

A few things I've shipped:

- Early web-AR try-on apps at FaceCake (~2011) — computer vision in the browser,
  including the NARS Cosmetics virtual try-on that drove a ~$400K/month revenue lift.
- One of the earliest production React UI libraries on Storybook at Freebird —
  200 components across web and React Native.
- A 50+ component design system at Redesign Health that cut dev time 30% across a
  10–15 engineer org (and a promotion to Engineering Director along the way).
- ForgeKit — my open-source Figma-to-React CLI + MCP suite (5,700+ npm installs)
  that bridges design tokens and typed React code for AI-native workflows.

Lately I work at the intersection of design systems, frontend, and AI-assisted
development — building the tooling I want for myself, and helping teams fold
Claude Code, Cursor, and MCP into real production work without losing the craft.

Open to Principal / Senior Frontend, Product Engineer, and design-systems /
developer-tooling roles.
